## 端口约定：改一处就够

**所有端口与串口缺省值都集中在 `hsfsrv/ports.py`。**

```python
PY_SERVER_PORT = 6200      # 服务端监听端口（改这里）
C_SERVER_PORT = 6100       # C 版端口（协议规格值）
SERIAL_PORT_WINDOWS = "COM17"      # 桌面端缺省串口
SERIAL_PORT_POSIX = "/dev/ttyS3"   # 板端缺省串口
```

改 `PY_SERVER_PORT` 一处即可，服务端监听、客户端缺省连接、`--help`
显示、部署脚本全部自动跟随。

**为什么要和 C 版（6100）错开**：让两套服务端可以同机并存做对比调试
（共用端口会让后启动的起不来）。协议完全一致，客户端 `--port` 选边即可。

> 客户端目录下有一份**内容完全相同**的 `ports.py`（两端独立部署，
> 不能互相 import）。`tests/test_ports.py` 会逐字节比对两份。

## 这是什么

一台采集现场仪表并向上位机提供实时数据的服务端：

- **链路**：TCP（XLink v2）+ 二进制 BSON 载荷，登录鉴权、订阅推送
- **采集**：一路 RS485（变频器 + 温湿度 +〔可选〕流量计 +〔可选〕浊度仪 ×2）
  + 三个 Modbus TCP 设备
- **控制**：变频器启停/调速（频率或转速）/点动、数字量 DO 输出、电磁阀 6 路、
  进水泵 1 台
- **约束**：自动模式下拒绝全部远程控制；点动看门狗 600ms 超时停机；
  电磁阀每路 20s 动作定时器，超时推送告警（**进水泵无反馈 ⇒ 无超时告警**）

## 三十秒上手

```sh
# 本机（桌面端：串口缺省 COM17，端口缺省 6200）
python -m hsfsrv --help
python -m hsfsrv --diag        # 先自检设备连通性
python -m hsfsrv               # 起服（6200）

# 无硬件时：虚拟设备（**只换设备层，业务层全真实**）
python -m hsfsrv --sim
python -m hsfsrv --sim --sim-valve-move 25    # 电磁阀行程 25s>20s ⇒ 验证超时告警
python -m hsfsrv --sim --sim-valve-move -1    # 阀卡死

# 无硬件时：独立模拟器（整个服务端都是假的，C 端联调用）
python ../sim/hsf_sim.py --show

# 无硬件时用假设备自测
python tests/run_all.py

# 板上
sh deploy.sh --no-serial      # 部署 + systemd + 起服务
ssh root@192.168.0.10 'journalctl -u hsfserverpy -f'
```

> **Windows 双击启动**：用同级目录的 `run_server.bat`（内部走 `python -m hsfsrv`）。
> **别直接双击 `hsfsrv/__main__.py`** —— 相对导入会失败、控制台一闪就没
> （程序本身没问题，只是启动方式错）。

## 设备一览

| 设备 | 链路 | 地址 | 关键口径 |
|---|---|---|---|
| M512/M513 变频器 | RS485 | `/dev/ttyS3` 站 2 | 频率 0x1001 单位 0.01Hz；**转速无寄存器**，按 50Hz≈1440rpm 换算 |
| 温湿度 ZS-SHT30 | RS485 | `/dev/ttyS3` 站 4 | FC04 ×2，各 ×0.1 |
| 模拟量 8 路 4~20mA | TCP | `192.168.0.11:8234` | `I(mA) = mV / 249Ω`；**通道0 = 压差计**（4~20mA → 0~1MPa） |
| 数字量 **32DI/32DO** | TCP | `192.168.0.12:502` | `.13` 聚合进 `.12`（**偏移 16**）；FC02 读 DI / FC01 读 DO / FC05 写 |
| 数字量 16DI/16DO | TCP | `192.168.0.13:502` | 被聚合者；`publish=false`（照常轮询出健康，不重复发点位） |
| 电磁阀 6 路 | 经 `.12` | DO16..21 / DI16..27 | 每路 1 DO + 2 DI（**先关到位、后开到位**） |
| 进水泵 1 台 | 经 `.12` | **DO22** | 6 路阀的**下一个口**；**只有输出、无运行反馈** ⇒ 无超时告警 |
| 电磁流量计 LD | RS485（**默认关**） | `/dev/ttyS3` 站 5 | FC03 一帧读 0x1010×22；32 位量高字在前。`--sim` 下自动挂虚拟流量计 |
| 浊度仪 ×2 | RS485（**默认关**） | `/dev/ttyS3` 站 **1 / 3** | FC03 读 0x0000×2，`NTU = raw/100`。⚠ **无资料，按常见口径**（见 03§5b） |

## 目录结构

```
server_py/
├── README.md            本文件（索引）
├── docs/                独立文档集
├── deploy.sh            板端部署脚本
├── run_server.bat       Windows 双击启动
├── cfg/                 运行期配置（首次自动生成）
├── hsfsrv/              服务端实现
│   ├── proto.py         线协议常量 + 帧头编解码
│   ├── bson.py          BSON 编解码（标准库）
│   ├── auth.py          登录认证 + 账户库
│   ├── xlink.py         XLink 服务端会话层
│   ├── modbus.py        Modbus RTU/TCP 主站
│   ├── devices.py       设备驱动
│   ├── app.py           业务层
│   ├── valves.py        电磁阀设备层（点位/状态/告警）
│   ├── pumps.py         进水泵设备层（DO 输出/幂等/外部改动接管）
│   ├── autocontrol.py   自动运行控制层（骨架，逻辑待扩展）
│   ├── virtualdev.py    虚拟设备层（--sim：只换 master，业务层全真实）
│   └── config.py        配置
├── tools/               运维脚本（自愈/改 IP/串口探测/模块配置）
└── tests/               单元 + 端到端测试
```

同级目录 `../sim/hsf_sim.py` 是**独立设备模拟器**（假服务端），
设备没到位时用它跑界面，C 端客户端也能直连。
