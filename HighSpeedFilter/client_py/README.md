# HsfClientPy — 高速过滤器客户端（Python 版）

对应 C 版 `HighSpeedFilter/client/`，**18 个页面、导航树、三段式界面、
主题色板与 C 端逐项对齐**，可直连 C 版或 Python 版服务端。
（一级菜单「设备」下含数字量/模拟量/搅拌泵/水质监测/电动球阀；
「监视」旧称于 2026-11-10 改名。）

部署目标：RK3568（Debian 11 / Python 3.9 / PyQt5 5.15）`192.168.0.10`。

## 三十秒上手

```sh
# 开发机（Windows 需先 pip install PyQt5 -i 清华镜像）
python -m hsfsrv_client --help
QT_QPA_PLATFORM=offscreen python tests/test_client.py       # 自测 36 项
QT_QPA_PLATFORM=offscreen python tests/test_vfd_combo.py --port 6200   # 组合点按 29 步×N 轮

# 没有服务端/设备时：起独立模拟器（假服务端）再看界面
python ../sim/hsf_sim.py --show                    # 数字量页
python ../sim/hsf_sim.py --show --page-name vfd    # 变频器页
python ../sim/hsf_sim.py --show --page-name analog # 模拟量页（压差计）

# 板上
sh deploy.sh --auto 192.168.0.10        # 部署 + 配开机自启（连 6200）
ssh root@192.168.0.10 'systemctl stop run_test.service'     # 让出屏幕
ssh root@192.168.0.10 'cd /root/Desktop/XinYueC/hsf_client_py && \
    DISPLAY=:0 ./launch.sh --auto 192.168.0.10 --fullscreen'
```

> **Windows 双击启动**：用同级目录的 `run_client.bat`。启动时会自动探测
> 本机 6200/6100，探测到就直接以 root 登录，不用填登录框。

## 端口约定：改一处就够

端口集中在 `hsfsrv_client/ports.py`（与服务端那份内容必须完全相同）：

```python
PY_SERVER_PORT = 6200      # 缺省连接端口（改这里）
C_SERVER_PORT = 6100       # C 版端口（--port 6100 时用）
```

缺省连 6200（Python 版服务端）；要连 C 版服务端加 `--port 6100`。
两套协议完全兼容，错开端口只为让两套服务端同机并存做对比调试。

## 18 个页面

主界面 · 主菜单 · 设备（数字量/模拟量/搅拌泵/水质监测/电动球阀）· 数据（历史/日志/报警）·
设置（本地/远端/网络/悬浮窗/窗口）

页序与 C 端完全一致（含索引编号）；**显示名有两处按本端工艺改**：
第 5 页「变频器」→「搅拌泵」（设备类别仍显示变频器）、第 6 页「流量计」
→「水质监测」。详情见 [01 文档 §4](docs/01-部署与运维.md)。

## 功能

| 功能 | 说明 |
|---|---|
| 登录 | 挑战应答；记住服务器/用户名（**不存口令**）；可离线浏览 |
| 遥测 | 变频器/温湿度/模拟量/数字量/健康，**只订阅当前页需要的** |
| 搅拌泵控制 | 启动/停机/自由停车/故障复位/频率给定/**按住式点动**（设备是变频器，页名按工艺用途） |
| 数字量 | DI 灯阵列（自绘圆点）+ DO 可点按钮，点数由服务端 `count` 决定；灯阵/按钮阵按窗宽**自适应列数**（窄窗不截断名称） |
| 电动球阀 | 6 路开/关；按**服务端处置结果**（`ignored`/`repeated`）置灰，不在本地猜 |
| 水质监测 | 流量计 + 浊度 ×2 + 进水泵启停；浊度带水温（站3 机型）；流量计报警**中文**（空管/上限/下限/系统）；**泵无运行反馈**（界面已注明不是"实测在转"） |
| 运行模式 | 手动/自动切换（需 root）；自动模式拒绝全部远程控制；**切模式全停设备**，只有按「启动」才允许工作 |
| 设备健康 | 顶栏「故障N/离线N」+ 首页设备表 + 报警页边沿记录 |
| 历史数据 | 服务端分页查询（`0x0118`）+ **页内表格/图表双视图**；筛选按时间/关键字/列，图表按筛选取全量（≤12000 行，每线 ≤2000 点）；线上列 19（含水温）、显示列 16 |
| 趋势图 | 设备/水质页实时趋势：X 轴**时钟时间**、Y 轴 5 档刻度；「采集速度」200/500/1000/2000ms 可调并持久化 |
| 本地设置 | 全部持久化到**程序目录** `cfg/hsf_client_py.ini`（不用注册表；旧注册表一次性迁移） |
