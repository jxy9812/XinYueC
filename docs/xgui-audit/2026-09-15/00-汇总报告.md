## 二、跨模块系统性问题（P0，建议先行）

1. **UTF-8 BOM 缺失**：Application 1 + Widget 4 + Graphics 9 + Icon 3 + Platform 4 头/1 实现 + Window 1（Protected.h）≈ 23 个文件。全部公共头硬约束 4 违规。
2. **守卫外遗留旧 API**：Widget 模块约 380 处（33 个 .c 空实现，位于 `#endif`/`extern "C"` 之外），违反约束 7「旧 API 不保留」，且破坏裁剪构建与 C++ 链接。
3. **拥有型字符串违规**：XComboBox.m_items/XTabBar.m_titles（char**）、XPlatformTheme.m_name（char[64]）、XPlatformNativeInterface 注册表（char*）、多个 const char* 主版本无 XString 主版本/_2 重载（Platform 系统性、Charts 全模块、Application setSessionState 等）。
4. **XMemcpy 复制对象**：XWindowEvent.c 7 处、Charts VXChart_move/VXSlice_move，违反约束 6。
5. **继承链错误/缺失**：XFusionStyle→XWindowsStyle（应 XCommonStyle）；缺 XPaintDevice（Graphics 全族 + XWidget）；缺 XAbstractAxis（Charts 轴）；XStyleSheetStyle 链正确但 XStyle 虚表 7 槽远小于 QStyle。
6. **空实现（约束 3）**：Widget 约 40 处真实 Qt API 空实现（XMessageBox/XTabBar/XTextEdit/XMainWindow/XCalendarWidget/XComboBox/XMdiArea/XWizard 等）；Style 绘制大面积缺 case。
7. **信号缺失/参数缺失（约束 5）**：XAbstractItemView 7 个全缺、XMessageBox::buttonClicked、XTextDocument 7 个、XComboBox 7 个参数、XAbstractSlider 4 个参数等。
