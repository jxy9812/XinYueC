## 1. 通信参数（附录 1）

| 参数 | 地址 | 含义 | 范围 | 出厂 |
|---|---|---|---|---|
| Pd.00 | 0xFD00 | 通讯波特率（**复合值**：千位 CANlink / 十位 Profibus / 个位 MODBUS） | 个位 0~9 | 6005（= MODBUS 9600） |
| Pd.01 | 0xFD01 | MODBUS 数据格式 | 0=8N2 / 1=8E1 / 2=8O1 / 3=8N1 | 0 |
| Pd.02 | 0xFD02 | 本机地址 | 0=广播，1~247 | 1 |
| Pd.03 | 0xFD03 | MODBUS 应答延时 | 0~20 ms | 2 |
| Pd.04 | 0xFD04 | 串口通讯超时时间 | 0.1~60.0 s | 0.0（无效） |
| Pd.05 | 0xFD05 | 通讯数据格式 | 个位 0=非标准（从站多回 1 字节）/ 1=标准 | 手册自相矛盾（p.42=31 / p.72=0），**以实机读取为准** |

帧格式：CRC16（多项式 0xA001，初值 0xFFFF，**低字节在前**）；地址与数据**高字节在前**；
3.5 字符静默间隔；错误帧 `0x83/0x86` + 错误码（01 命令码 / 02 地址 / 03 数据 / 04 无法处理）。

### 2.1 「通讯设定值」的百分比基准（易错点）

0x1000H 是**相对最大频率 P0.10 的百分比**，不是绝对 Hz，也不是固定 50 Hz：

```
raw = round( Hz / P0.10 × 10000 )        Hz = raw / 10000 × P0.10
```

P0.10 = 50.00 Hz 时 10000 恰好等于 50 Hz；P0.10 = 5000 Hz 时 10000 等于 5000 Hz。
本项目在 `XVfdM512.c` 中以「读 P0.10 → 缓存基准 → 换算」实现（基准未读到时按 50 Hz 兜底）。

### 2.2 0x1000H 是 16 位补码（已修的真缺陷）

原实现把频率给定当无符号量写通道层，`xIoAnalogPointToRaw` 会把负值**钳成 0** →
反转给负频率静默失效。现已在点规格中标注 `m_signed`，由基类 `XVfdDevice_writeRole`
在写通道前做补码归一（`raw & 0xFFFF`）。

## 4. 功能码（参数）地址编排

| 组 | 读取 / 写 EEPROM | 只改 RAM（不落盘） |
|---|---|---|
| P0~PE | 0xFxxx | **0x0xxx**（把 F 换成 0） |
| A0~AC | 0xAxxx | **0x4xxx**（把 A 换成 4） |
| PP | 0xFFxx | 手册未给变体 |

- 同一参数**有两个地址**：写 EEPROM 地址与只改 RAM 地址。只改 RAM 省 EEPROM 寿命
  （手册附录 1 明确提醒）。本项目在 `XVfdParamDesc.m_addrRam` 中登记 RAM 变体。

- 组内空洞（手册未印的编号，如 P0.20 / U0.4x / U0.5x）**不映射即不读**。

## 6. 现场前置条件（上电前必须确认）

1. **P0.02 = 2（命令源 = 通讯）** —— 否则 0x2000H 命令字被**静默忽略**。
2. **P0.03 = 9（主频率源 = 通讯给定）** —— 否则 0x1000H 频率给定被**静默忽略**。
3. **PA.00 = 5（PID 给定源 = 通讯给定）** —— 用 PID 通讯给定时必需。
4. **Pd.02 = 从站地址（1~247）**、**Pd.00 个位 = 波特率编码**、**Pd.01 = 数据格式**。
5. 输出端子的功能选择须为「通讯控制」才响应 0x2001H / 0x2002H~0x2004H 强制。

本项目把这三条源切换做成了**显式 API**（而不是隐式自动改用户配置）：

```c
bool XVfdM512_setCommandSourceComm(XVfdM512* dev);    /* P0.02 = 2 */
bool XVfdM512_setFrequencySourceComm(XVfdM512* dev);  /* P0.03 = 9 */
bool XVfdM512_setPidSourceComm(XVfdM512* dev);        /* PA.00 = 5 */
```

并且在 `Start` / `SetFrequency` / `SetPidTarget` 之前**同步校验**当前源值：
若已读到且不是通讯通道，立即报 `XVfdError_WriteRejected` 并给出明确提示，
**不再让命令被从站静默吞掉**。

## 8. 上电初始化序列（推荐）

```
读 0xFD02  确认本机地址（应等于组帧里的 unitId）
读 0xFD00  确认波特率复合值（个位 = MODBUS 波特率编码）
读 0xFD05  确认标准/非标准 Modbus-RTU
写 0xF002 = 2      （P0.02 命令源 = 通讯）
写 0xF003 = 9      （P0.03 主频率源 = 通讯给定）
读 0xF00A          （P0.10 最大频率，作为百分比换算基准）
需要 PID 通讯给定时：写 0xFA00 = 5
需要复位/初始化能力时：写 0xFF00 = PP.00 密码 → 回读 8888H → 30 s 内写 0xFF01
```
