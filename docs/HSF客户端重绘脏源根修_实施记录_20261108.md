# HSF 客户端重绘脏源根修与帧耗时回归（实施记录）

> 日期：2026-11-08（承接 2026-11-07 客户端 UI 批次）
> 现象：悬浮层「帧耗时」长期 500~632ms、界面明显卡；各页帧数虚高（数字量
> 159.8fps、电磁阀 60.9fps、变频器 32.4fps），用户口径「画面变化很慢，正常
> 就该一两帧、耗时 0.0x ms」。
> 结论：**方向一度走错**（加过全局 2fps 帧率闸——那是造假读数，已撤除）。
> 真正要修的是**持续标脏源**；本轮共定位 12 类，全部根修，帧耗时回到
> 1.1~2.4ms、稳态帧数 1~3fps。本文是完整台账与诊断口径，改重绘问题先读这里。
> 晚间收尾批次（两项回归根修、跨车道全量回归、临时探针清理、导航分割条
> resize 显隐同值早退）见
> `docs/HSF会话收尾与两项回归根修_实施记录_20261108.md`。

|---|---|---|---|---|
| 主界面 | 3.9 | 0.91/1.62 ms | 2.0 | 1.43/1.64 ms |
| 数字量 | **159.8** | 1.11/9.52 ms | **2.0** | 1.58/1.65 ms |
| 模拟量 | 1.9 | **13.46/25.71 ms** | 2.0 | 1.79/2.37 ms |
| 变频器（停机） | **32.4** | 3.61/20.74 ms | **3.0** | 1.16/1.65 ms |
| 变频器（35Hz 运行） | — | — | 3.0 | 1.27/1.71 ms |

> 不是两帧间隔。旧口径把间隔当耗时，2fps 档下自然读到 507ms/632ms。

## 2. 诊断口径（先量再改，禁止猜）

框架自带画像，全部环境变量门控（`XGUI_*` 在 Src/XGui，`XHSF_*` 在客户端）：

| 变量 | 输出 | 用途 |
|---|---|---|
| `XGPU_W_FRAME_PROF=1` | 每 3 秒 `[wprof]` `[rprof]` `[rprof3]` `[lprof]` | **主力**：`[rprof3]` 按「父类/自身类」直方图点名谁在标脏 |
| `XHSF_PTREE_TRACE=1` | `[ptree-own]` 单控件 paintEvent ≥5ms | 找单个自绘控件的耗时（VFD 仪表 66ms 即此查出） |
| `XHSF_PAINT_TRACE=1` | `[paint] page=%d rect=… tree=%lldus` | 看每帧区域与整树耗时 |
| `XHSF_BAR_METRICS=1` | `[bar-metrics] avail/level/need1/need2` | 数据工具条分档是否够宽（窄窗截字） |
| `XGUI_FLUSH_DIRTY_UNION=0` | 恢复「只信 PAINT 快照」旧口径 | §4 语义改动的回退开关 |
| `XGUI_DIRTY_NO_VISIBLE_CLIP=1` | 脏区退化为控件自身客户区 | 脏区裁剪异常对照 |
| `XGUI_FLUSH_BBOX_MERGE=1` | 多矩形脏区收拢成外接矩形 | 旧口径对照 |
| `XGUI_FLUSH_FULLFALLBACK=1` | 脏区空时退整窗 | 首帧/异常对照 |

判读要点：
- `[rprof3]` 里某业务控件**笔数≈帧数** ⇒ 它就是节拍器（每帧都在标脏它）。
- `[lprof] inval` 异常大 ⇒ 布局失效风暴（重复 setVisible/setSize 之类）。
- `[wprof] fr/gap` 看帧间隔；`paint` 段是本帧绘制。

## 3. 脏源台账（逐条：根因 → 修法）

### R1 全局 2fps 帧率闸（**方向错误，已撤除**）
- 位置：曾挂在 `XWidget_postPaintEvent`（`XGUI_REPAINT_MAX_FPS`）。
- 后果：弹层被拦成空白、交互延迟 500ms、帧耗时读成帧间隔。
- 处理：**整体删除**（`XGuiConfig.h` 留勘误注）。Qt 没有全局重绘闸：
  `update()` 只合并脏区、有脏区就画，节奏由平台合成器天然限制。
- 现存限频宏只有：`XGUI_RESIZE_REPAINT_MAX_FPS`（默认 30，仅窗框拖拽/
  改尺寸手势，跳过的中间位移按锚点+总位移无状态重算天然合并、松手补尾帧）
  与 `XGUI_PRESENT_MAX_FPS`（默认 0 不限，仅上屏提交段；跳帧把提交矩形
  并回脏区账本，不改绘制频率）。

### R2 帧耗时口径错误
- `VHsfWin_paintEvent` 曾把「上次绘制时刻」当帧起点 ⇒ 读数是帧间隔。
- 修法：改用整树绘制耗时回填（`XWidget_lastPaintTreeUsecs`），量「上一帧
  真实画了多久」。

### R3 setText 之后又显式 update / setPalette 无同值早退
- `XLabel_setText` 内部已 `updateGeometry + update`，外面再 `XWidget_update`
  等于废掉同值早退（主页 15 标签 × 5Hz）。
- `XWidget_setPalette` 补 **Qt `QWidgetPrivate::setPalette_helper` 同款
  同值早退**（qwidget.cpp:4629-4633）。业务侧「按状态着色」不必再补 update。
- 修法：删冗余 update；框架补早退（`HsfHomePage.c`、`XWidget.c`）。

### R4 隐藏页仍在按节拍刷新
- `HsfMonitorVfd` 的 200ms 定时器在页切走后照样 `vfdRefresh` 全页回填
  （实测 49 次/秒布局失效）。
- 修法：刷新入口过 `XWidget_isVisible` 闸；数据本身继续推进，切回下一拍补齐。

### R5 悬浮层自身刷新过密
- `XGUI_PERFORMANCE_OVERLAY_UPDATE_MS` 250 → **1000**（诊断读数 1Hz 够）；
- `updateNetwork` 不再自己刷新文本，统一归统计窗口（否则每秒两次文本变化）；
- 悬浮层宽度按 8px 量化，避免读数每变一次就重摆锚点（右贴边旧位/新位各脏一次）。

### R6 复杂自绘控件用「上千条 AA 细线拼面」
- VFD 仪表弧带：底盘 ~1430 条 + 底轨 ~1080 条 + 描边 ~600 条 AA 径向线，
  单表 66ms。
- 修法（对齐 Qt）：`XPainterPath` + `XPainter_fillPath` 一次路径填充（4×4
  覆盖光栅化一次完成）；**静态层**（底盘/底轨）缓存进 `XImage`，每帧只
  blit + 画进度弧。66ms → 6ms。

### R7 整板自绘看板：一张卡变化整板重画（模拟量/数字量）
- 模拟量 8 卡 10Hz 推送实测 **13.46/25.71ms**。
- 修法（`HsfMonitorAnalog.c` / `HsfMonitorDigital.c`）：
  1. 标脏按**卡片/点格矩形**（`XWidget_updateRect`），不再整块看板；
  2. paintEvent **消费 PAINT 矩形**：translate 之后
     `XPainter_setClipRect(&painter, &XPaintEvent_rect(pe), ReplaceClip)`，
     跳过与脏区不相交的卡片/段标题（光栅有裁剪，但文字整形/省略号计算的
     开销裁剪兜不住）；
  3. 卡片矩形计算与绘制公式**同源同参**（`analog_cardRect` /
     `digital_cellRect`），改版面必须两处同改。
- 模拟量页另补：`setEngineering`/`setName`/`setUnit` 同值早退（单位/说明是
  静态配置，10Hz 重放不必 alloc/free）。

### R8 电磁阀页：`setEnabled` 先启用再禁用（每拍两次真翻转）
- `valveCardApply` 原写法：
  `setEnabled(close, canControl); if (Closed) setEnabled(close, false);`
  —— 关阀钮每拍「启用→禁用」两步**真实状态翻转**（setEnabled 只在真变时
  标脏）。6 卡 × 20Hz ⇒ 开/关钮 240 笔脏区/秒、阀页 60.9fps。
- 修法：**先算最终态一次下发**：
  `openEnabled = canControl && state != Open; closeEnabled = ...`。
- 同页另一处：`XWidget_setVisible` 每拍重复调用。框架的 setVisible **刻意
  不做同值早退**（显隐承载布局激活），重复调用会 `XLayout_invalidate` 父布局
  ⇒ 实测 662 次失效/秒。调用点先比 `XWidget_isHidden()`。
- `HsfMonitorValve_setControlEnabled` 补同值早退（闸门每拍由
  `hsfWinApplyControlGates` 重算下发）。

### R9 快照重放常量字段：业务层 setName 无早退（数字量 159.8fps）
- 快照每次推送重放 16 个点位名称，`HsfMonitorDigital_setName` 每条都
  alloc/free + 标脏 ⇒ 单次推送 16 笔脏区。
- 修法：业务层先 `strcmp` 同值早退（XLabel 的早退管不到这里的堆分配）。

### R10 裸字面量语句 ⇒ 画未初始化栈缓冲（3 处显示 bug）
- 症状：模拟量卡片「原始」行恒空、两段标题恒空、无名点显示垃圾。
- 根因：`"原始: N mV";` 这类**把注释当占位**的空语句编译照过，真正画出去的
  是未初始化 `char buf[]`。
- 修法：全部改 `snprintf`（`analog_drawCard` 原始行 / `analog_drawSectionTitle` /
  `analog_displayName` 兜底；数字量 `digital_displayName` 的 `"点 N"` 格式串
  漏 `%d` 一并修）。
- 复查口径：`grep -rn '^\s*"[^"]*";\s*/\*' HighSpeedFilter/client/`

### R11 模拟量卡片高度没给第四行留位
- 越限说明（`m_engNote`）画在 `y+18+3*textH`，旧高度公式只有三行 ⇒ 说明被
  卡片底边切掉（无裁剪时更糟：糊在邻卡上）。
- 修法：`cardH` 按四行留高。

### R12 VFD 仪表取数走错槽（联机弧线永远 0%）
- `VHsfVfdGauge_paintEvent` 直取 `provider->device()->status_const`；远端
  （XLink）provider 的 `device()` **恒返回 NULL**（无本地设备对象）⇒ 数值标签
  有值、进度弧永远画不出来。
- 修法：统一走 `vfdPageStatus`（snapshot 优先、device 回落）。横幅早已如此，
  仪表漏了同一处口径。**同页多套数据源必然打架**。

## 4. 框架语义对齐：PAINT 区域 = 入队快照 ∪ 当前脏区

- Qt 6.8 `QWidgetWindow::handleUpdateRequest` **忽略** `QUpdateLaterEvent`
  携带的区域，按控件此刻累积的 dirty 区一次画完
  （`toClean = dirty; dirty = QRegion();`）。
- 本框架此前直接信 PAINT 事件**入队时的快照**：一次推送里连续标脏 N 个单元格
  ⇒ 首个事件只含第 1 格，其余 N-1 格等尾部重投再画 ⇒ **N 笔标脏 = N 帧**
  （数字量页 16 点 × 10Hz 实测 159.8fps）。
- 修法（`XWidget.c` flush）：`whole = PAINT快照 ∪ top->m_dirty`。事件快照仍
  必须并入——EXPOSE 区域可能不在 m_dirty 里，只画脏区会漏掉暴露块。
- 诊断回退：`XGUI_FLUSH_DIRTY_UNION=0`。

## 5. 数据工具条窄窗自适应（历史页 1024/1280）

- 分档判据从「形态位」改为**工具条实际可用宽**（`barVisibleWidth` 取祖先链
  最小宽）：⓪ 标签全显+常规最小宽 → ① 收说明标签 → ② 再收控件最小宽+行距
  → **③ 隐去「共 N 行」**（它是两行里唯一纯只读计数；历史页状态行已有
  「共 N 条 … 库内共 N 条」）。
- 「共 N 行」最小宽改为 **max(档位基准, 当前文本实测宽+6)**：5 位数
  「共 11020 行」需 ~78px，写死 64 会把末尾「行」截掉。
- 实测：1024（level 3，无窗外溢出）/ 1280（level 1，关键字框完整）/ 1600
  （level 0，标签全显）三档截图验收。

## 7. 复现命令

```bat
:: 服务端（模拟口径）
bin\HsfServer.exe --sim

:: 客户端离屏截图 + 稳态读数（--page：0 主页 / 3 数字量 / 4 模拟量 /
:: 5 变频器 / 7 电磁阀 / 9 历史数据）
set XHSF_SHOT_DELAY_MS=12000
bin\HsfClient.exe 26 --login root:root@127.0.0.1:6100 --page 4 ^
    --shot out.png --size 1280x800

:: 脏源画像
set XGPU_W_FRAME_PROF=1
:: 工具条分档
set XHSF_BAR_METRICS=1
```

> 连续两次连接间隔约 8s（DenyNew 下旧会话按静默超时回收，立即重连会被拒）。
> 联调失败先查是不是**机器上有多个 HsfServer 实例**（旧会话占着 root，
> 服务端回 bad password、控制权被占，表现为泵/阀按钮置灰）。

## 8. 遗留 / 未闭环

- 历史页第二排控件在**极小宽**（<1000）下的进一步压缩策略：当前到 level 3
  为止，再窄只能靠滚动/换行布局（框架无流式布局）。
- 真实窗口最小化/还原只做了静态核对（离屏无法模拟）。
- `[rprof3]` 直方图槽位上限 16 类（`XWIDGET_RPROF_CLASS_MAX`），复杂页面
  超出部分不计数（不影响主力判读）。
