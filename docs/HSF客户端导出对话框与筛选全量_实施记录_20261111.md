# HSF 客户端「导出走文件对话框 + 按筛选全量」实施记录（2026-11-11）

## 用户口径（本轮原话）

> 「导出改走文件对话框，格式选择外部的下拉删除，在文件对话框中选择格式，
> 并且导出的数据是按照筛选的来，不仅仅是表格显示的哪些，还有很多表格
> 没显示的，因为这是分页表格，数据菜单下的三个界面中的表格都是这个要求，
> 记得要做测试闭环」

拆解：

1. **删**工具条「导出格式」下拉（删干净：控件本体、Feature 位、读写 API、
   三页调用点；不许留死控件/空标签/"选了不兑现"残留）。
2. 导出弹框架文件对话框 `XFileDialog_getSaveFileName_2`，filter 串
   `Excel 工作簿 (*.xlsx);;CSV (*.csv)`；格式由对话框自建的
   「文件类型(T)」下拉（selectedFilterIndex 回填）决定，**不自造格式 UI**。
3. 导出内容 = **按当前筛选条件的全部命中行**（分页表格屏幕只有几十行，
   命中的是全部）——按页向服务端累加，全部写进同一个文件。
4. 历史/日志/报警三页都改；必须带 `export=true`（服务端验 Download）；
   上限截断要显式进状态行；不抽样；落盘路径来自对话框。
5. 测试闭环：①验证筛选本身正常；②确定性回归锁；③三页覆盖；
   ④端到端复检脚本无人值守跑。

## 三条根因备忘（为什么这么做）

1. **锚点漂移**：`hsfLcHistoryQuery` 旧实现把 `beforeTs` 恒发成发包当下
   （HsfLinkClient.c 旧 2683-2684）。服务端 `hiMs=min(hiTs,beforeTs)`——
   用户没设 hiTs 时每批窗口上界都在长，逐批顺序取会**重复/漏行**。
   修法：`historyQueryWindow` 加 `beforeTs` 形参（<=0 回退旧行为），导出
   循环整轮钉同一个锚。端到端 A2（各批 total 稳定 + 去重==total）就是
   对这条的锁。
2. **limit 撞键**：应答槽只有一份，页面按服务端回显的 (offset,limit) 认领。
   导出批若用 50 与页大小档位同键 ⇒ 迟到应答错认领铺错表（历史页复审②
   同源）。批行数走 41..49 轮转（复用 `HsfChartZoom_nextLimits`），编译期
   闸 + §Q5 双锁。
3. **权限闸不许绕**：历史页导出全量仍逐批带 `export=true`（服务端
   HsfServerApp.c:2242 验 Download），不许借图表通道（不带 export）取数
   落盘。端到端 A4（admin 降级匿名 → 拒绝包络、无数据；不带 export 仍能
   读）钉住"拒的是导出闸不是连接"。

## 截断上限（openQuestion 的拍板）

行缓存按显示格文本（历史页 16 列 × 48B ≈ 0.8KB/行），上限取
`HSF_EXPORT_PLAN_MAX_ROWS = 12000`（与图表内存上限同量级，≈9.5MB 峰值）；
超出**显式截断**并在状态行报「已导出 N 行（共 M 行，超出上限截断）」。
不抽样是导出的铁口径——截断是唯一省略方式，且必须可见。实测后要放大
再改这一个宏（批计划自动跟随）。

## 格式判定细则（openQuestion 的拍板）

对话框选「Excel 工作簿」但手输 `.csv` ⇒ **按手输扩展名出 CSV**（过滤器
下标只是没输已知后缀时的缺省）——与 Python 端 pages_other 的「扩展名
决定」分支对齐；框架不自动补扩展名 ⇒ 补全责任在
`HsfExport_resolveFromDialog`（`.csv`/`.xlsx` 不分大小写）。

## caveats

- **§P 编号冲突**：调查给的「新增 §P 导出批次计划段」里 §P 已被既有
  「带给定启动＝一个动作」（testP1_startWithGivenIsOneAction）占用，
  实际落成 **§Q**。
- **Python 端客户端本轮不动**：pages_other.py 仍只导当前页（另一端
  独立行为）；要对齐属 Python 侧另立任务。
- **报警页无服务端分页协议**：报警记录是客户端边沿缓冲（上限 200 即
  全量），导出本就是筛选命中全量——只改了对话框取路径/格式，无取数
  状态机（与历史/日志页的差别记在 HsfDataAlarm.c 注释里）。
- 文件对话框的真窗口交互（模态 exec）无法无人值守自动点按；端到端
  脚本验证的是协议面契约（服务端筛选/锚点/权限），C 端状态机行为由
  §Q + 编译期闸钉住；真对话框取消/选格式路径已在无 GUI 桩下确认走
  「已取消导出」分支（桩返回空串）。
