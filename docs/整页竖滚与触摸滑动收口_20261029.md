# 整页竖滚与触摸滑动收口（2026-10-29）

## 需求

XGuiDemo 全部界面：内容超高时出现垂直滚动条（AsNeeded，装得下不出条）；
触摸滑动支持移动设备操作习惯（手指方向=内容移动方向，跟手+惯性）。
框架层能力下沉框架，页面零散壳统一收口。

## 结论

- **框架**：`XAbstractScrollArea` 新增触摸跟手滚动+惯性（默认开启，全部
  滚动区子类受益：XScrollArea/条目视图族/文本编辑族）；手势状态机新增
  「滚动拖动 Track 模式」原始位移流通道。
- **Demo**：未自带滚动承载的页面统一在堆叠条目层包
  `DemoScrollHost→XScrollArea` 壳（豁免表甄别已自带整页滚动的页面）；
  内建页 0~4/12 同收入口。
- **验证**：注入式探针 `XScrollTouchProbe_Test` 12/12 全绿；24 个页面
  420x640 逐页截图通过（滚动条按需出现、桌面形态不变）。

## 框架改动

### 1. 手势状态机 Track 滚动拖动模式（XWidget.c/XWindowEvent.h）

- `XTouchGestureKind` 扩展 `DragUpdate=5/DragEnd=6/DragCancel=7`；
  新增 `XTouchDragMode`（SimulateMouse=历史默认 / Track=滚动拖动），
  `XTouchEvent` 增加 `m_dragMode` 标记位（setDragMode/dragMode）。
- DragBegin 判定询问：接受控件在事件上标 Track → 框架把挂着的合成左键
  press 以远偏移释放关闭（按钮按下态就地解除），本序列后续 UPDATE/END/
  异常收口改发 DragUpdate/DragEnd/DragCancel **原始位移流**（位置=当前
  主点，逐接收者坐标换算）；SimulateMouse（默认）与无人接受路径逐位保持
  历史行为（标题栏/悬浮窗/紧凑键盘零改动）。
- **[根修] TOUCH_DRAG 命中坐标补口**（XWidget.c
  `XWidget_eventPosition/eventSetPosition`）：TOUCH_DRAG 此前不在指针
  位置读写分派表 → 手势事件恒以 (0,0) 命中——历史消费方不用坐标靠冒泡
  兜底侥幸可用，Track 模式逐帧差分依赖位置，在此显式补口（DragBegin
  判定域从此真正=按压落点）。

### 2. 滚动区触摸跟手+惯性（XAbstractScrollArea）

- 虚表新增 `TouchDragEvent/TimerEvent/HideEvent` 槽；DragBegin 可滚
  （任一条 range>0）且开关开才认领标 Track，DragUpdate 按帧差分直接写
  滚动条（跟手 1:1 无量化，dy>0=值减=内容随指下移）；DragEnd 按采样环
  （4 槽/150ms 窗）估速度启动惯性：16ms 粗定时器拍、每 16ms ×0.95 指数
  衰减、1e-3 px 余数累积（亚像素不丢步）、尾速 <40px/s 或端点顶死停机
  （对标 Android 列表边界急停）。DragCancel 只停跟手不给惯性。
- 停滚收口：滚轮（基类/XScrollArea 覆写两侧）、滚动条把手 sliderPressed
  （连接随 setVertical/HorizontalScrollBar 替换同步挂摘）、resize、隐藏、
  开关关闭。
- 公开 API：`XAbstractScrollArea_set/touchScrollEnabled`（默认 true；
  关=回落历史合成滚轮量化语义）；保护入口
  `XAbstractScrollArea_stopTouchScroll`（XAbstractScrollArea_Protected.h，
  供子类自管输入路径调用）。
- TimerEvent 槽按 timerId 守卫：只消费本区惯性拍，子类业务拍（如
  XPlainTextEdit 自动滚动经 XClass_Parent 链入）原样链回父类，历史行为
  逐位保持。

## Demo 改动（xgui_window_demo.c）

- `DemoScrollHost`（XWidget 子类，resizeEvent 铺满内嵌滚动区）+
  `demo_wrap_page_scroll_ex`：堆叠条目=壳（竖条 AsNeeded/横条
  AlwaysOff/widgetResizable(true)）→ 真页根。不直接把 XScrollArea 入栈
  （堆叠对其条目几何分配异常，network/modbus 同款实证）。
- **身份契约不变**：`m_extPages[]`/`m_page*` 成员仍指真页根——逐页
  adapt/autotest/大表格收编/远程 isWindow 门按真根消费，零感知。
- 豁免表 `g_extPageScrollReady[19]`：dialogs/timeddns/atv61/modbus 从站
  /Shell（真根=滚动区）、network/modbus 主站（页宿主内嵌壳）、菜单页
  （页内容即导航滚动容器）不再包裹，防双层滚动条。
- 包裹页：views/advanced/effects/keyboard/remote_server/remote_client/
  overlay_settings/qrcode/update/window/testmenu + 内建 0~4/12。
- `m_pageScrolls[26]`（页索引→壳滚动区）：`demo_layout_content` adapt
  漏斗收尾按当前页 `XScrollArea_updateWidgetGeometry` 一次——页内档位
  重排改内容提示后滚动范围即时跟上（统一收口 network/modbus 页各自
  adapt 显式调用的同款刷新）。
- **[顺序约束] views 大表格收编先于包裹**：收编把 mid-init（vtable 未
  装）的表格插入页根布局——root 尚无几何时布局激活惰性（历史行为）；
  先包后收编会让 setWidget 的立即排版激活布局，mid-init 表格被 sizeHint
  虚调用崩溃（420x640 --page 5 实证）。hook 移到 demo_ext_ensureBuilt
  包裹之前。

## 验证记录

- `XScrollTouchProbe_Test`（新增独立探针，自带 main，CMakeLists 注册；
  已从 XGuiWindowDemo_Test 测试树收编中剔除）：
  跟手 1:1+方向 / 惯性启停/钳口/停稳不漂移 / tap 零滚动 / 不可滚不认领 /
  开关回落滚轮量化（100px 手指=+60 一格）且无惯性——12/12 全绿。
- Demo 逐页截图（XGUI_DEMO_WINDOW_SIZE=420x640）：页 0~23 全部正常构建
  渲染；超高页（窗口设置/远程窗口/条目视图等）右侧出竖条，桌面
  1000x700 形态与改前一致（装得下不出条）。
- 触摸滚动条把手回归：把手按下即 grabMouse，DragBegin 不会询问到滚动区
  （手势状态机抓取者在位分支），把手拖拽不受影响。
