## 2. 单 lane 工作协议（发现 → 修 → 自验）

每个 lane 拿到台账后按此流程（**禁止改测试期望掩盖问题**）：

1. **读台账**：逐条读自己辖区的 A/B/C/D 条目，标注「可立即实现 / 需框架机制 / 不适用」。
2. **优先做 D（行为差异）**：单条成本低、用户可感知、门禁可验。
3. **A 缺失按档位**：档1 才做（框架核心语义必需）；档2/档3 记入「后续增量」不硬做。
4. **B 冗余逐条复核**：台账结论**必须独立复核语义等价性**（已实证一条需修正，
   见施工规格 §4.1 裁定修正）；能删的给出迁移方案 + 调用点统计，**与主线程确认后**再删。
5. **C 改名**：改名是**破坏性**的——先补新名（薄封装转发旧名）、迁移调用点、
   旧名标 @deprecated 保留一个版本周期，最后才考虑删旧名。
6. **自验**：构建用 `flock /tmp/xinYueC_audit.lock` 串行（禁止并行 make）；
   测试用 `DISPLAY=:99` 对应族；失败集必须 ⊆ 基线。
7. **报告**：逐条给「Qt 侧证据文件:行 + X 侧落点文件:行 + 验证输出」。

## 3. 汇总与统一编译（用户要求的核心）

**lane 之间不各自跑最终全量构建**（会互相踩构建目录——项目历史反复踩过：
「make 竞态 + 半成品诱导乱修」「L 路并行编辑 dispatcher 协调警告」）。

汇总阶段（主线程执行）：

1. **冲突检查**：各 lane 报告改过的文件，重叠即人工裁决。
2. **统一构建**：`flock` 内 `make -j8 XinYueC_Static XGuiWindowDemo_Test XGuiRegression_Test`
   + 裁剪构建（`.zcode/wf-gates/wf_trim_gate.sh`）。
3. **统一门禁**：`.zcode/wf-gates/wf_qtalign2_gate.sh final`
   （五套件零中断 + gest/scroll 零失败 + reg 零失败 + 零新失败）。
4. **回归对照**：失败集与基线（`.zcode/wf-gates/qtalign2_1029/`）逐条比对。
5. **独立复核**：派独立复核 lane 审 diff（对象所有权、init/deinit 配对、
   失败路径、别名语义、引用计数、线程安全、C99 兼容）。

## 4. 门禁与硬约束

- **程序中断零容忍**：任何套件 RC ≥ 128 / 124 / 137 = 硬失败。
- **不得提交 git**（待用户授权）。
- **不得回退他人改动**（工作树含多会话痕迹）。
- **约束文档合规**：Doxygen 中文注释、`_base` 只查表分派、`XString` 规则、
  时间源走 `XDateTime`、禁 `malloc` 族、UTF-8 BOM、Protected 头自包含。
- **新增惰性容器/拥有型字段必须同步查析构路径**（W1 已踩过：m_actions/m_locale
  曾漏释放 → 每个控件泄漏）。

## 5. 用户裁定（2026-10-30，全部照办）

1. **可见性下沉：全做**——Qt protected/private 被提升为 public 的 API 一律下沉到
   框架的 `XClassName_Protected.h`（施工规格 §4.2 的 6 组 + 各路台账同类项）。
   约束文档硬性要求：公开头只放公有 API，protected 虚函数/内部存储位进
   Protected 头；Protected 头必须自包含（`#include "XClassName.h"`），
   调用方须显式 include（用 `rg` 扫全部调用方逐个补）。
2. **图表：全做**——L14 的 QtCharts 对标面（252 条缺失）本轮**全部补齐**，
   不做「只出分期建议」。A6 lane 升级为完整施工 lane。
3. **改名：即删旧名**——C 改名不做 @deprecated 双名过渡，直接
   「补新名 → 迁移全部调用点 → 删旧名」一步到位（调用点统计先行，
   确认零残余再删）。
4. **mcgs 部署：统一部署**——第二段施工全部完成后统一 armel 构建 + 部署 +
   逐项真机验证（不逐批上屏，避免半成品占用设备与反复重启）。
