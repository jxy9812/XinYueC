## 1. 第二波疑题与本协议的解剖设计

- 疑题：GPU 增量每帧 ~1.36ms（SW 0.09ms）花在哪。增量基准经静态层缓存后
  脏区只剩悬浮层 210x50，每帧仍有毫秒级开销。候选：glReadPixels 同步停顿
  （管线冲刷+往返）、批冲刷、begin/end 帧固定成本、呈现链。
- 解剖设计：增量口径三态对照把「读回面积」与「读回同步性」两个候选拆开
  量化——
  - **dr1 vs def**（XGPU_DIRTY_READBACK=1 回退全窗读回，默认态为脏区读回；
    开关语义以 `XWidget.c:5999-6018` 为准）：拉开幅度 = 帧成本对读回面积
    的敏感度（第一波已证 ≈+12%）；
  - **pbo0 vs def**（XGPU_PBO_READBACK=0 同步读回，默认态为 PBO 异步读回；
    PBO 落地前为空操作）：拉开幅度 = 同步停顿的敏感度；
  - **两者都不拉开** → 瓶颈在批冲刷 / begin-end 固定成本 / 呈现链，转
    XGPU_PROF 计时器深挖（协议外跟进）。
- 空闲 CPU 口径补第一波 C 路验证欠账：空闲闸门治理后 --gpu 空闲负载应从
  163% 降到近零；**预演实测未达（64–68%，见 §5.4），欠账如实入档**。

## 2. 协议（第二波口径：对第一波三处加厚，历史格口径不变可纵比）

1. **增量口径每格三态** {def, dr1, pbo0}（§1）；每态显式净化子进程环境
   （def 移除两键、单态键互斥，不受父会话残留 env 污染），日志带 `env:`
   取证行；SW 格照跑三态充「开关不触碰软件路径」的天关对照（沿
   night3-final §3 惯例，免掉第一波手工跑两遍脚本的对照法）。
2. **page 5（条目视图，慢页跟踪）入矩阵**：页面 4→5；`--page 5` 在
   show() 前切页，基准模式照常生效（xgui_window_demo.c 参数解析即此序）。
3. **空闲 CPU 口径**：--gpu 普通启动（无基准、默认页、不交互），落窗稳定
   3s 后采 TotalProcessorTime，静置 5s 再采；load = ΔCpu/ΔWall×100
   （**单核算术口径，多线程可 >100%——第一波 163% 即此算法，纵比必须
   同法**）；两态 {gate-def, gate0（XGUI_DEMO_IDLE_GATE=0 回退旧「帧泵
   逐轮强制重绘」口径）}。
4. **闪烁 30 帧项原样保留**（--gpu --page 4 普通启动，PrintWindow 抓 30
   帧 + 差分，changed>500 帧对数）。
5. 不变口径：exe 复制 `%TEMP%\xgui_bench3.exe` 运行、每遍前后 taskkill；
   `--benchmark 5` 秒栅 ×2 遍取第 2 遍；整帧口径单态 def（全窗失效下
   readbackRect 的 bbox 即整窗、自然退化为全帧读回，开关对照无意义，
   night3-final §3 实证）。

## 4. 达标判据（终测只认数字）

1. **主判据（任务书固定）：GPU/SW ≥1 的格数——增量口径 ≥2 格。**
   以主表默认态 fps 为准（5s 栅 ×2 取第 2 遍），任意两页达标即达成。
2. 整帧口径：不设反超目标（60Hz 呈现限频 + 全帧成本，第一波结论），设
   **不回归带**：page 0/2/4/6 比值不低于第一波终测带 0.054–0.091 的 80%
   （即 0.043–0.073）；page 5 为新跟踪格，本轮终测数值即其基线，只记录
   不判（预演已示其为全矩阵最重格：整帧 GPU 仅 4.5 fps，见 §5.2）。
3. 开关收益（次表）：
   - 脏区读回收益 (def−dr1)/dr1：GPU 各页 **≥+8%** 计「收益复现」（第一波
     +10.8–13.2%）；SW 同列 **|收益| ≤3%** 计「天关对照干净」（超限按
     波动加跑复核，2s 缩尺预演的 SW 噪声带见 §5.3）。
   - PBO 收益 (def−pbo0)/pbo0：PBO 已落地时 GPU 各页 **≥+5%** 计「PBO
     生效」；未落地（本预演 exe）则 pbo0 即基线，差值应落在噪声带
     （预演实证：常规页 ±5%、慢页单遍可到 ±27%——任何超带差值先查
     是否真的落地了开关再谈收益）。
4. **空闲 CPU：gate-def ≤5%（近零）为达标**；gate0 不设阈值（回退态对照，
   预期高位——它证明闸门是收益来源）。预演实测 gate-def 64–68%、gate0
   ~200%，**未达近零**；终测前需先定位空闲残留负载（候选：呈现链 60Hz
   空转、事件循环轮询、残留定时器），终测如实记录当时值。
5. 闪烁：changed>500 帧对保持 **0/29**（第一波已根治）。

## 6. 诚实性声明

- 预演全部数值出自本次实跑（命令与产物路径见 §5）；格式校验 13 项数字为
  探针实际输出，探针用后即删；空闲复跑为独立第二次实跑，非推算。
- 预演口径为 2s 栅 ×1 遍缩尺（协议默认 5s×2 取第 2 遍），预演数值不可
  直接当终测结论；文中一切「带/量级」比较均两边同口径或注明口径差。
- `XGPU_PBO_READBACK` 当前全源码无定义，pbo0 态为空操作——其差值按噪声
  处理，不作为任何收益证据。
- 空闲 gate-def 实测 64–68% 与任务书预期「近零」不符，按实测如实入档，
  未做圆场；第一波 163% 数字引自任务书，本夜 gate0 实测 ~200% 与其同
  量级但非同刻测量，纵比须以终测同法重采为准。
- 本脚本对构建目录 exe 只读（复制到 %TEMP% 运行），未跑任何构建，未改
  Tools/docs 之外任何文件。
