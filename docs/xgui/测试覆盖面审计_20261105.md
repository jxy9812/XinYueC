## 六、已知偏差登记（有意保留，勿当回归）

1. **rowAt/indexAt/itemAt 坐标域含表头**：Qt 的 QTableView 坐标域是
   viewport 系（不含表头），本库恒含顶部表头带（全族断言与命中链
   自洽）。改域是波及全库交互链的独立战役，本审计仅登记。
2. **XSettings atomicSync 默认 true**（Qt atomicSyncOnly 默认 false）+
   取锁超时 0ms（Qt QLockFile 默认等 30s）——嵌入式不可阻塞 30s 的
   有意取舍（见 xsettings-posix-lockfile-1104）。
3. **XKeyboardLayoutKind 默认 PinyinFull**（LVGL 经典表退居 setMap/
   User 槽位）——1028 键盘适配战役裁定。
4. **XGUI_REPAINT_MAX_FPS / 慢帧时序适配**：时序断言「墙钟窗+兑现泵」
   定式已入 XKeyboardTest/XTouchMultiPointTest（cf7fbf69）。
5. **apitest 浮动 ±1**：DateTimeEdit setCalendarWidget(NULL) 懒创建
   竞态（六连 1,0,1,1,0,0）——与 10-30 浮动集同性质，登记勿追。

## 七、结论

- 门禁面：ctest 6/6 + 三套件全绿 + 主程序 18 个专项全绿 + apitest 九族
  独立进程全绿（57 条稳定失败清零）。
- 覆盖面：核心模块全部有直测；薄弱面集中在 XFile/XSync/XAlgorithm 直测
  与 9 个低频控件（G1~G5，已排优先级）。
- 纪律：新增带 main 专项必须走 TEST_FILE 剔除三查；时序断言用
  「墙钟窗+兑现泵」定式；行为修复批次必须同步翻转 apitest 断言口径。
