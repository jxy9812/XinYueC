## 1. 方法

- 全页扫描：`Tools/sweep/run_sweep.bat` 串行执行 后端 {sw(裸启动), gpu(--gpu)} × page{0..8} × `--screenshot Tools/sweep/<mode>_p<N>.png`（exe 渲染 3 帧后内部读回落盘退出：GPU 走 FBO readback、SW 走 `XWidget_paintImage`，见 `test/XGuiDemo/xgui_window_demo.c:1288-1338`）。18/18 RC=0。
- 后端口径探针：裸启动 p0 截图 MD5 与 `--sw` **完全一致**（BC898AA01142FA9023208AB0FE044557）、与 `--gpu`（04522A510209DB8C4551650F3D7719C3）不同 → 裸启动=SW 后端，「SW 裸启动」口径成立。
- 两两差分：`Tools/sweep/pair_diff.ps1`（2px 采样，通道和阈值 30，输出 changed/bbox/100×100 cell 热区）+ 本道真实读图目检（Read 工具逐张看，非只看差分数）。
- 静态闪烁：`Tools/sweep/flicker_pg.bat` → 起 `--gpu --page N` 常驻实例 → `Tools/capture_frames.ps1`（PrintWindow PW_RENDERFULLCONTENT，120ms×30 帧）→ `Tools/diff_frames.ps1`（3px 采样，阈值 30/通道和）。
- 交互闪烁：`Tools/sweep/interactive.bat` = 起实例 → 后台 `Tools/sweep/wait_capture.ps1` 抓 20 帧 → `Tools/sweep/click_tabs.ps1`（SetCursorPos+mouse_event，导航行客户坐标 nav4=(398,57)/nav6=(570,57)/nav0=(54,57)，源自 `xgui_window_demo.c` nav 行 `x=12+nav*86,y=44,w=84,h=26`，与 night3-interactive.md 实测一致）→ WM_CLOSE 优雅退出保 stdout 冲刷。
